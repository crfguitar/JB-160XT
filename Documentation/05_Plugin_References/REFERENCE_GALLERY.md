Images are original vendor downloads or native embedded pixels extracted from vendor PDFs. No images were generated, sharpened or enlarged to claim extra detail. Dimensions describe the entire image canvas, which may contain margins or a scene around the interface.

## Direct XT reference: Overloud Comp160

The strongest XT-specific plugin reference found in this search is Comp160's explicit XT model. Its [vendor product page](https://www.overloud.com/products/comp160) distinguishes VU, XT and A and states that the reference XT had an optional transformer. That is a vendor description of its own model, not a measurement of your unit. Source IDs: WEB01, PL02.

This is larger than the [1200 x 167 product-page XT panel](Images/Overloud_Comp160_XT_Main.jpg). It includes plugin-specific controls below the hardware-inspired panel.

## Original-160-family comparators

These references are useful for control legibility, layout, metering and comparative behavior. They are not verified XT models.

![Waves flat dbx160 interface](Images/Waves_dbx160_Flat_UI.png)

- [Waves flat UI](Images/Waves_dbx160_Flat_UI.png): direct vendor asset with CDN height restriction removed; exact dimensions are in the manifest. [3000 x 1500 promotional hero](Images/Waves_dbx160_Hero.png) is also retained, but the flat UI is more useful for controls. [Waves manual](Manuals/Waves_dbx160_User_Guide.pdf), source PL01, describes a hard-knee feedforward VCA model and its added controls.
- [UA dbx160 gallery image, 1248 x 980](Images/Universal_Audio_dbx160_Gallery.png): original product image without a requested CDN resize. The [saved online manual](../00_Index/Source_Pages/Universal_Audio_dbx160_Online_Manual.txt) describes its sidechain filter and mix behavior. Those features do not establish an XT detector curve.
- [NI VC160 manual image](Images/NI_VC160_Manual_UI.png): native embedded screenshot from PDF p16 of the [Vintage Compressors manual](Manuals/NI_Vintage_Compressors_VC160_Manual.pdf). This is a historical Guitar Rig-era manual; avoid assuming its format/compatibility details describe a current standalone plugin.

## Hardware reference

[Official dbx 160XT image, 4096 x 2271](../06_Hardware_Visuals/dbx_160XT_Official_Front.webp) is the manufacturer's original available hardware asset, source HWIMG01. For exact scales, colors and LED counts on your particular unit, your own photographs will be stronger evidence than any vendor emulation.

Use these graphics for research and comparison. For a shipped recreation, create original interface artwork and retain the distinction between hardware controls and added digital conveniences.
